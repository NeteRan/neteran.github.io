# 网络安全学习计划清单

::: tip 定位
从零实战到 CTF 参赛 · 独立渗透测试。适用起点：已了解 SQL 注入 / XSS 原理、会基本 Kali 命令行。目标：**参加 CTF 获奖 · 独立完成网站渗透测试**。
:::

> 制定时间：2026 年 11 月

## 一、总体判断与学习主线

你的核心断层不是「不懂原理」，而是「**懂原理但不会用**」。因此这份计划的基调是：**边补基础、边刷题**，比例随阶段调整，而不是「先学完理论再上战场」。

### 三条贯穿始终的主线

1. **编程（Python 为主）**：从第一周就开始学，不要等漏洞都懂了再学代码。没有代码能力，你改不动 exploit、写不了自动化 PoC，CTF 的 Web 题和渗透里的自定义 payload 都做不了。
2. **Web 漏洞**：SQL 注入、XSS、CSRF、SSRF、文件上传、文件包含、命令注入、XXE、越权、反序列化。这是你两条目标线（CTF Web 题 + 网站渗透）的**共同核心**。
3. **渗透方法论**：信息收集 → 漏洞扫描 → 漏洞利用 → 提权 → 后渗透 → 报告。

> **一句话结论**：你不是「先补基础还是先刷题」的二选一，而是「边补基础边刷题」。因为你已有理论基础，纯补基础会浪费时间，纯刷题又会卡在工具和代码上。

## 二、分阶段学习路线

### 阶段 1 · 底座加固（第 1–5 周，约 5 周）

这是你最该花时间的地方。零实战的人最容易栽在「看不懂报错、不会用工具、不会写脚本」上。

| 模块 | 学习内容 | 阶段目标 |
|------|---------|---------|
| Linux / 命令行 | `find` / `grep` / `awk` / `sed`、管道与重定向、`netcat` / `curl`、权限与用户、进程管理 | 能独立完成「拿到 shell 后做信息收集、提权」所需的全部命令 |
| 网络基础 | TCP/IP、HTTP 协议细节、DNS、常见端口与服务 | 能用 Wireshark 分析一次 HTTP 请求，看懂三次握手 |
| 编程语言 | Python（主线，写 PoC / 自动化 / 编 exp），辅以 JS | 能写 50–100 行脚本自动化攻击或解题 |
| 工具链 | Burp Suite、Nmap、Gobuster / Dirsearch | 熟练使用，不再「看着教程点按钮」 |

**本阶段清单：**

- ☐ 系统过一遍 Kali 常用命令，并每天手敲巩固
- ☐ 用 Python 写一个可运行的端口扫描 / 目录爆破脚本
- ☐ 熟练 Burp Suite 的 Proxy、Repeater、Intruder 三大模块
- ☐ 用 Nmap 完成一次主机端口 + 服务版本扫描

### 阶段 2 · 漏洞原理 + 靶场实战（第 6–13 周，约 8 周）

> 原则：**一个漏洞 = 学原理 + 打靶场**，同步推进，不脱节。

**学习内容（按顺序推进）：**

1. **Web 漏洞**：SQL 注入（Union / 报错 / 盲注）、XSS、CSRF、SSRF、文件上传、文件包含（LFI/RFI）、命令注入、XXE、越权（IDOR）、反序列化。
2. **渗透方法论**：信息收集 → 漏洞扫描 → 漏洞利用 → 提权 → 后渗透 → 报告，学习 PTES 或 OWASP 测试流程。
3. **提权基础**：Linux / Windows 常见提权手法（SUID、内核漏洞、服务配置错误等）。

**本阶段清单（逐漏洞打勾）：**

- ☐ SQL 注入（含 Union、报错、盲注）
- ☐ XSS（存储型 / 反射型 / DOM 型）
- ☐ CSRF
- ☐ SSRF
- ☐ 文件上传漏洞
- ☐ 文件包含（LFI / RFI）
- ☐ 命令注入
- ☐ XXE
- ☐ 越权 / IDOR
- ☐ 反序列化
- ☐ 掌握渗透测试完整流程
- ☐ 掌握 Linux / Windows 常见提权手法

**阶段目标**：每个漏洞都能在靶场上**独立复现**，而不是照着 writeup 一步步点。

### 阶段 3 · CTF 专项 + 渗透实战（第 14–19 周，约 6 周）

- **CTF 线**：主攻 Web、Crypto（密码学）、Misc 三类（与你基础匹配度最高），pwn / 逆向等编程再扎实后再说。
- **渗透线**：在合法靶场上完成**完整**渗透流程，从信息收集到提权到写报告。

**本阶段清单：**

- ☐ 在 CTF 平台刷 Web 题，稳定解出基础题
- ☐ 入门 Crypto（古典密码、常见现代密码题型）
- ☐ 入门 Misc（隐写、流量分析、取证基础）
- ☐ 在 HackTheBox / VulnHub 完成 3–5 台靶机完整渗透
- ☐ 完成至少 2 份完整渗透测试报告

### 阶段 4 · 进阶与打磨（第 20 周起，长期）

- ☐ 参加真实线上 CTF，熟悉比赛节奏
- ☐ 补齐 Crypto / 逆向 / Misc 弱项
- ☐ 挑战 HTB 更难机器，精读高质量 writeup
- ☐ 复现 CVE、学习内网渗透 / 域渗透

## 四、学习优先级建议

> 核心结论：**先补基础，但基础要和实战立刻挂钩**，不要「纯学理论等刷题」。

| 阶段 | 比例 | 说明 |
|------|------|------|
| 第 1 个月 | 7 分基础、3 分实战 | 主攻 Linux + Python + HTTP，同时每周打 2–3 个 DVWA 漏洞保持手感 |
| 第 2–3 个月 | 5 分靶场、3 分原理、2 分代码 | 以 PortSwigger Academy 为主线，一个漏洞一个漏洞过，遇到盲注/自动化顺手练 Python |
| 第 4 个月起 | 7 分实战、3 分复盘 | 打 CTF、做渗透靶机，每道题/每台机器必写复盘 |

::: warning 复盘规则
每道题 / 每台机器结束后，记录「思路、卡点、学到了什么」。**没有复盘的刷题等于白刷。**
:::

## 五、时间预估（从入门到参赛 / 独立渗透）

| 里程碑 | 所需时间 | 达成标志 |
|--------|---------|---------|
| 能独立打 Web 靶场漏洞 | 1–2 个月 | 不靠 writeup 复现常见 Web 漏洞 |
| 能参加 CTF 并解出部分题 | 3–4 个月 | 线上赛 Web 题做出 2–3 道，Misc / Crypto 入门 |
| 能独立完成一次网站渗透 | 4–6 个月 | 在 HTB / VulnHub 完整走通「信息收集→利用→提权→报告」 |
| 具备 CTF 获奖能力（团队/校赛级） | 6–12 个月 | 稳定解出 Web + 部分其他题型，熟悉比赛节奏 |

> **总览**：每天投入 2–3 小时，**6 个月左右**能「独立完成网站渗透测试」并「参加 CTF 稳定拿分」；**12 个月持续投入**能冲击小比赛奖项。若每周投入不足 7 小时，时间线相应拉长约 1.5 倍。

## 六、立即开始的三个行动

1. **本周**：在本地搭一个 DVWA，把你「懂原理」的 SQL 注入、XSS 亲手复现一遍，立刻暴露「理论懂但不会用」的具体差距。
2. **今天就定主线**：注册 PortSwigger Web Security Academy（免费），作为接下来两个月的 Web 漏洞主线。
3. **本周就写**：开始写第一份「漏洞复盘」模板，为后续刷题建立复盘习惯。
