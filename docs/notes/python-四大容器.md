# Python 四大容器：列表、元组、字典、集合

::: tip 一句话概括
列表是「可变的排队」，元组是「定死的清单」，字典是「查名字找东西」，集合是「去重和算交集」。
:::

Python 里最常用的四种「容器」（container），就是用来装一组数据的家伙。它们长得像，但脾气完全不同。这篇把它们的区别、用法、适用场景一次讲清楚。

## 先看一张对比表

| 特性 | 列表 list | 元组 tuple | 字典 dict | 集合 set |
|---|---|---|---|---|
| 写法 | `[1, 2, 3]` | `(1, 2, 3)` | `{'a': 1}` | `{1, 2, 3}` |
| 是否可变 | ✅ 可变 | ❌ 不可变 | ✅ 可变 | ✅ 可变 |
| 是否有序 | ✅ 有序 | ✅ 有序 | ✅ 有序（3.7+） | ❌ 无序 |
| 能否重复 | ✅ 可重复 | ✅ 可重复 | key 不重复 | ❌ 自动去重 |
| 查找方式 | 下标 / 遍历 | 下标 / 遍历 | 键 key | 成员判断 |
| 查找速度 | 遍历 O(n) | 遍历 O(n) | 极快 O(1) | 极快 O(1) |
| 典型用途 | 存一串东西 | 常量 / 多返回值 | 键值映射 | 去重 / 集合运算 |

## 一、列表 list：可变的排队

列表是最常用的容器，一个**有顺序、能改、能重复**的集合。

```python
fruits = ['苹果', '香蕉', '橙子']
print(fruits[0])        # 苹果（下标从 0 开始）
fruits.append('葡萄')    # 尾部加一个
fruits[1] = '草莓'        # 改第 2 个
print(fruits)           # ['苹果', '草莓', '橙子', '葡萄']
```

### 常用操作速查

```python
nums = [3, 1, 2]
nums.sort()            # 排序 [1, 2, 3]
nums.reverse()         # 反转 [3, 2, 1]
nums.insert(0, 9)      # 在下标 0 插入 9
nums.pop()             # 弹出并删除最后一个
nums.remove(2)         # 删除第一个值为 2 的元素
len(nums)              # 长度
3 in nums              # 判断是否包含 → True/False
```

### 切片：列表最实用的技巧

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]     # [1, 2, 3]  从下标1取到3（不含4）
a[:3]      # [0, 1, 2]  从头取到下标2
a[3:]      # [3, 4, 5]  从下标3取到结尾
a[::2]     # [0, 2, 4]  每隔一个取
a[::-1]    # [5, 4, 3, 2, 1, 0]  倒序（超常用）
```

### 列表推导式：一行生成列表

```python
# 常规写法
squares = []
for i in range(5):
    squares.append(i * i)

# 推导式写法（简洁得多）
squares = [i * i for i in range(5)]   # [0, 1, 4, 9, 16]
```

## 二、元组 tuple：定死的清单

元组和列表几乎一样，唯一区别是**创建后不能改**（不可变）。

```python
point = (3, 4)
print(point[0])     # 3
# point[0] = 5      # ❌ 报错！元组不能改
```

### 为什么要有元组？既然列表都能干

1. **安全**：不想让数据被意外改掉，用元组更放心。
2. **性能**：元组比列表轻量，创建更快。
3. **可作字典的 key**：元组不可变，能当字典键；列表不能。
4. **多返回值**：函数返回多个值，本质就是返回元组。

```python
# 多返回值，本质是元组
def get_pos():
    return 100, 200

x, y = get_pos()     # 自动解包
print(x, y)          # 100 200
```

### 单元素元组的坑

```python
t = (1)      # ❌ 这不是元组，是 int！
t = (1,)     # ✅ 这才是元组，注意逗号
```

## 三、字典 dict：查名字找东西

字典存的是**「键 → 值」的映射**，靠键来查找，速度极快（O(1)）。

```python
person = {
    'name': 'NeteRan',
    'age': 20,
    'skills': ['Python', '网络安全']
}
print(person['name'])        # NeteRan
person['age'] = 21           # 改值
person['city'] = '深圳'       # 加新键值
```

### 常用操作

```python
d = {'a': 1, 'b': 2}

d.get('c', 0)         # 取 'c'，没有就返回默认值 0（比 d['c'] 安全，不会报错）
d.keys()              # 所有键
d.values()            # 所有值
d.items()             # 所有键值对
d.setdefault('x', 9)  # 有就返回，没有就设置并返回
d.pop('a')            # 删除并返回值
'a' in d              # 判断 key 是否存在
```

### 遍历字典

```python
for k, v in d.items():
    print(k, v)
```

### 字典推导式

```python
squares = {x: x * x for x in range(5)}   # {0:0, 1:1, 2:4, 3:9, 4:16}
```

::: tip 什么时候用字典？
需要「通过一个东西查另一个东西」的场景。比如：用户名查密码、单词查翻译、id 查用户信息。只要你想「按名字/编号找人」，就用字典。
:::

## 四、集合 set：去重和算交集

集合是**无序、不重复**的一堆元素，最大的本事是「自动去重」和「集合运算」。

```python
s = {1, 2, 3, 3, 2, 1}
print(s)          # {1, 2, 3}  自动去重了
```

### 集合运算（数学里的交集并集）

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a & b       # 交集 {3, 4}
a | b       # 并集 {1, 2, 3, 4, 5, 6}
a - b       # 差集 {1, 2}（在 a 不在 b）
a ^ b       # 对称差 {1, 2, 5, 6}（只在一边的）
```

### 最实用的场景：去重

```python
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))    # [1, 2, 3]
```

### 成员判断极快

```python
# 判断一个数在不在一个超大数据集里，用集合比列表快得多
big_set = set(range(1000000))
999999 in big_set    # 极快 O(1)
```

::: warning 集合的坑
集合是无序的，所以**不能靠下标取元素**（`s[0]` 会报错）。而且集合里不能放列表这种可变对象（因为集合靠哈希去重，要求元素可哈希）。
:::

## 五、怎么选？一张图记住

```
需要「按顺序存一串，还要改」      → 列表 list
需要「定死不变的一串」            → 元组 tuple
需要「按名字/键查值」             → 字典 dict
需要「去重」或「算交集并集」      → 集合 set
```

### 一个综合小例子

```python
# 统计一段文字里每个单词出现的次数
text = "apple banana apple orange banana apple"
words = text.split()

# 用字典统计
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
print(count)   # {'apple': 3, 'banana': 2, 'orange': 1}

# 去重看有哪些单词（用集合）
unique_words = set(words)
print(unique_words)   # {'apple', 'banana', 'orange'}
```

## 六、常见坑总结

| 坑 | 说明 |
|---|---|
| 元组单元素忘加逗号 | `(1)` 是 int，`(1,)` 才是元组 |
| 字典用 `d['不存在的键']` | 直接报错，改用 `d.get(key, 默认值)` |
| 集合用下标取元素 | 集合无序，没有下标 |
| 列表当字典的 key | 列表可变不可哈希，会报错；改用元组 |
| 修改遍历中的列表 | `for x in lst` 时改 lst 会导致奇怪结果，遍历时别删改 |

---

## 总结

| 容器 | 一句话记忆 | 典型场景 |
|---|---|---|
| 列表 list | 可变的排队 | 存待办事项、商品列表 |
| 元组 tuple | 定死的清单 | 坐标、多返回值、常量 |
| 字典 dict | 查名字找东西 | 用户名→密码、配置项 |
| 集合 set | 去重和算交集 | 去重、共同好友 |

::: tip 进阶提示
这四种容器可以互相嵌套、互相转换（`list()`、`tuple()`、`set()`、`dict()`），配合列表/字典推导式，能写出很简洁的代码。熟能生巧，多写几遍就记住了。
:::
